# Samanta TikTok Shop

Recovered production snapshot of the Samanta / Sunlix TikTok Shop landing page.

This repository preserves the deployed site captured from the production build, including the production HTML, CSS, JavaScript chunks, GSAP/ScrollTrigger motion code, timeline/carousel modules, images and video.

## Run

```bash
npm start
```

Open `http://localhost:4173`.

## Important

Read `RECOVERY_NOTES.md` and `docs/SAMANTA_PROJECT_HANDOFF.md` before changing the project.

The original uncompiled source repository was not available in the browser capture. This repository is the exact production-build recovery and should be treated as the visual/behavioral source of truth while readable source components are progressively reconstructed.
